# Blueprint: Low-Cost HTML5 Game Development & YouTube Dev Vlog

\#\# 1\. Executive Summary & Background  
The objective of this project is to build a portfolio of intuitive, mechanic-driven HTML5 web games using generative AI (Gemini CLI) for rapid code generation, while documenting the engineering process via a "Build in Public" YouTube dev vlog. 

By prioritizing browser-based web games over native app stores, the project maintains \*\*zero user friction\*\* (no downloads required) and \*\*zero mandatory platform fees\*\* (bypassing Apple/Google developer licenses). The development philosophy centers on maintaining a low-cost, low-overhead infrastructure that remains sustainable, rewarding, and highly enjoyable as a long-term creative outlet.

\---

\#\# 2\. The $0 Tech Stack & Tools Strategy  
To keep ongoing costs at absolute zero, the deployment, development, and hosting pipeline relies entirely on premium free tiers:

\*   \*\*Code Generation:\*\* Gemini CLI (leveraging daily free limits/existing API access).  
\*   \*\*Version Control & Code Storage:\*\* GitHub (Free public/private repositories).  
\*   \*\*Web Hosting:\*\* Vercel, Netlify, or GitHub Pages. (All offer generous free tiers that can host static HTML5/JavaScript games globally with high bandwidth capabilities).  
\*   \*\*Core Game Engine Libraries (Open Source):\*\*  
    \*   \*Physics puzzles (e.g., Rock Stacking):\* \`Matter.js\` (A lightweight 2D physics engine).  
    \*   \*Grid/Strategy games (e.g., Tower Defense, Chess):\* \`Phaser.js\` or Vanilla JavaScript.  
\*   \*\*Video Recording & Editing:\*\* OBS Studio (Free/Open-source screen recording) and CapCut or DaVinci Resolve (Free tier editing software).

\---

\#\# 3\. Phased Action Plan (One Step at a Time)

\#\#\# Phase 1: Local Environment & First Framework Setup  
\*Goal: Establish your local workspace and get a blank template running in a browser.\*  
\*   \[ \] \*\*Step 1.1:\*\* Create a dedicated project folder on your computer (e.g., \`/WebGamesProject\`).  
\*   \[ \] \*\*Step 1.2:\*\* Initialize a local git repository or simple directory structure:  
    \*   \`/index.html\` (The webpage container)  
    \*   \`/game.js\` (The game logic scripts)  
    \*   \`/assets/\` (For any sound effects or images)  
\*   \[ \] \*\*Step 1.3:\*\* Prompt the Gemini CLI to generate a basic "Boilerplate HTML5 Canvas webpage template with an active game loop." Run this file locally in Google Chrome or Safari to ensure your environment works.

\#\#\# Phase 2: MVP Development — Game 1: Rock Stacking  
\*Goal: Use AI to build a simple, intuitive physics-based game.\*  
\*   \[ \] \*\*Step 2.1:\*\* Prompt Gemini CLI to integrate \`Matter.js\` via a CDN link into your HTML skeleton.  
\*   \[ \] \*\*Step 2.2:\*\* Have the AI generate the core engine rules: a solid ground platform at the bottom, and the ability for a player to click anywhere on the screen to spawn a random geometric "rock" that drops due to gravity.  
\*   \[ \] \*\*Step 2.3:\*\* Refine the mechanics iteratively via the CLI:  
    \*   Add friction and mass settings to the rocks so they slide and tilt realistically.  
    \*   Implement a height-tracking script to record how high the player can stack the rocks before they fall.  
\*   \[ \] \*\*Step 2.4:\*\* Conduct local gameplay testing. (Optional: Hand the screen over to family members to test how intuitive the mechanics are without giving them instructions).

\#\#\# Phase 3: The Content Pipeline (Vlog Setup)  
\*Goal: Capture the build process without letting video editing drain your energy.\*  
\*   \[ \] \*\*Step 3.1:\*\* Set up a clean layout in OBS Studio to record your screen (coding interface \+ browser window) alongside a microphone.   
\*   \[ \] \*\*Step 3.2:\*\* \*\*Record the "Raw Wins & Fails":\*\* Do not script your videos. Record 15–20 minute segments of you prompting the CLI, running the code, encountering a funny physics bug (e.g., rocks flying off-screen), and fixing it.   
\*   \[ \] \*\*Step 3.3:\*\* Compile a 10-minute YouTube video focusing on a narrative hook: \*“Using AI to build a physics puzzle from scratch.”\*  
\*   \[ \] \*\*Step 3.4:\*\* Publish the game code to your free web host (Vercel/GitHub Pages), copy the live URL, and drop it in the very first line of your YouTube video description so viewers can click and play instantly.

\#\#\# Phase 4: Expansion & Iteration  
\*Goal: Branch out into new genres once the first pipeline is fully normalized.\*  
\*   \[ \] \*\*Step 4.1:\*\* Transition to \*\*Game 2 (Tower Defense)\*\* using \`Phaser.js\`, instructing the AI to create simple grid-placement logic and pathfinding enemies.  
\*   \[ \] \*\*Step 4.2:\*\* Transition to \*\*Game 3 (Chess Openings Trainer)\*\*, using basic JavaScript arrays to track board states and drilling specific counter-moves to popular openings.

\#\# 4\. Key Performance Indicators & Long-Term Viability  
Because the financial barrier to entry is controlled at $0, success is measured strictly by execution consistency and enjoyment:  
1\.  \*\*Code Sovereign Ownership:\*\* Every line of code generated via your CLI remains entirely yours, saved locally and backed up on GitHub. You are not locked into any proprietary cloud platform.  
2\.  \*\*Zero Pressure Monetization:\*\* If traffic scales organically via the YouTube vlogs, Google AdSense for H5 Games can be integrated down the road via a simple API function injection (\`adBreak()\`), turning the hobby into a passive income stream without changing the core workflow.
